# CLAUDE

This repository is an open-source Chilean SII SDK in Python. Follow the same rules as the project-level `AGENTS.md` instructions.

## Required behavior

- Follow the roadmap in `temp/ROADMAP.md`.
- Maintain semantic versioning tags with the format `v{major}.{minor}.{patch}`.
- Use Conventional Commits in English (`feat`, `fix`, `chore`, `refactor`, `docs`, `test`, `ci`, `build`).
- Keep documentation in English first and add Spanish localization when needed.
- Favor clean architecture and incremental delivery.
- Respect sync and async support as a design goal.
- Do not skip tests for functional changes.

## v0.1.0 objective

The first stable project milestone should establish the foundation of the SDK:

- package version and metadata
- SII environment configuration
- base error handling
- synchronous client baseline
- documentation and contribution structure

## Important instruction

Always guide your work by the repository `AGENTS.md` file. If there is any conflict between a local shortcut and the AGENTS guidance, the AGENTS instructions win.
