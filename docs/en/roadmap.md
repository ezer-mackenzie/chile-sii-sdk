# Roadmap

The roadmap is organized in phases and follows clear semantic versioning and conventional commits.

## Current focus

- package foundation
- auth and token lifecycle
- secure certificate handling
- DTE model and XML serialization
- sync and async client interfaces

## Version flow

- v0.1.0: foundation and project scaffolding
- v0.2.0: authentication and token acquisition
- v0.3.0: XML and DTE domain models
- v0.4.0: sync client
- v0.5.0: async client
- v0.6.0: DTE submission and status tracking
- v1.0.0: production-ready SDK

For full details, see the project roadmap in the temporary planning folder.
