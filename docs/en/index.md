# Chile SII SDK

The Chile SII SDK is an open-source Python project designed to simplify integrations with Chilean SII services.

This project is being built with a strong focus on:

- secure authentication and certificate handling
- XML generation and validation
- sync and async client support
- maintainable, documented, and type-safe APIs
- English-first documentation with Spanish localization support
