# Chile SII SDK

El Chile SII SDK es un proyecto abierto en Python diseñado para simplificar la integración con los servicios del SII de Chile.

Este proyecto se construye con un enfoque fuerte en:

- autenticación segura y manejo de certificados
- generación y validación de XML
- soporte para clientes síncronos y asíncronos
- APIs mantenibles, documentadas y tipadas
- documentación en inglés con soporte de localización en español
