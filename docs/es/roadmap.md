# Hoja de ruta

La hoja de ruta está organizada por fases y sigue una versión semántica clara y commits convencionales.

## Enfoque actual

- base del paquete
- autenticación y ciclo de vida de tokens
- manejo seguro de certificados
- modelos DTE y serialización XML
- interfaces de clientes síncronos y asíncronos

## Flujo de versiones

- v0.1.0: base del proyecto y estructura inicial
- v0.2.0: autenticación y obtención de token
- v0.3.0: modelos XML y DTE
- v0.4.0: cliente síncrono
- v0.5.0: cliente asíncrono
- v0.6.0: envío y seguimiento de DTE
- v1.0.0: SDK listo para producción

Para más detalles, consulta la hoja de ruta del proyecto en la carpeta temporal de planificación.
